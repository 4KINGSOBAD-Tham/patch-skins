# 4KING SOBAD - โฟลเดอร์สำหรับอัปเดตม็อด/สกินอัตโนมัติ

เพียงวางไฟล์หรือโฟลเดอร์ที่คุณต้องการอัปเดตลงในโฟลเดอร์นี้:
- `SAMP/custom.ide` (ไฟล์กำหนดรหัสสกิน)
- `texdb/samp.img` (ไฟล์โมเดลสกิน .dff)
- ฯลฯ

เมื่อกด Commit บน GitHub ระบบ GitHub Actions จะรวมไฟล์เป็น `patch.zip` และสั่งให้มือถือผู้เล่นทุกคนอัปเดตให้อัตโนมัติทันที!
