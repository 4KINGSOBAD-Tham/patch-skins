# 👑 4KING SOBAD - Server Config & Patch Manager

คลังควบคุมระบบเซิร์ฟเวอร์ 4KING SOBAD (สำหรับจัดการการตั้งค่าและอัปเดตม็อดสกินโดยเฉพาะ)

---

### 📂 โครงสร้างในหน้านี้:
1. 📄 **`manifest.json`** : ไฟล์ Hash สำหรับตรวจสอบไฟล์ตัวเกม PC Launcher (Anti-Cheat)
2. 📄 **`security.json`** : ไฟล์ตั้งค่าเซิร์ฟเวอร์สำหรับแอปมือถือ:
   - เปลี่ยน IP / Port เซิร์ฟเวอร์
   - ข้อความประกาศแถบวิ่ง (Announcement Marquee)
   - เปิด/ปิด สถานะเซิร์ฟเวอร์ (Online / Offline)
   - กฎการตรวจจับโปรแกรมโกง (Anti-Cheat Blacklist)
3. 📁 **`patch_files/`** : โฟลเดอร์สำหรับอัปเดตสกิน/ม็อดมือถืออัตโนมัติ
   - ลากไฟล์สกินหรือ `custom.ide` ใส่ในโฟลเดอร์นี้ แล้วกด Commit
   - ระบบ GitHub Actions จะรวมไฟล์เป็น `patch.zip` และสั่งอัปเดตผู้เล่นในมือถือให้อัตโนมัติ 100%!
